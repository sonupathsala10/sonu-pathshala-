# Sonu Pathshala

Responsive static website starter for a BSEB Class 10 learning hub.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Included
- Responsive homepage and navigation
- Search/filter across resource cards
- Dark mode toggle (saved in browser when storage is available)
- Study timetable generator
- Native share / WhatsApp share link
- Starter pages for books, notes, PYQ, tests, maps, diagrams, video lectures and games
- About and contact pages
- Uploaded reference image copied to `images/sonu-photo.jpg`

## Before publishing
1. Replace the header image with a properly cropped portrait if desired; the supplied image currently contains the full banner.
2. Add only verified, legal PDF downloads and official BSEB/NCERT links.
3. Add real YouTube channel, Telegram and social URLs.
4. Connect the contact form to a secure backend or form provider.
5. Add real content, answer keys and sources to placeholder pages.
6. Test on Android, iOS and desktop; enable HTTPS and configure hosting/domain.
7. If you add analytics or a backend, publish a privacy notice and protect contact-form data.

## Tech
HTML5, CSS3, vanilla JavaScript. Fonts load from Google Fonts when online. No build step required.
